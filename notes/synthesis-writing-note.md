# Synthesis Writing Note

This optional note helps reason about grounded prose. It is not a required workflow for every route.

Useful checks:

- Confirm the target section, audience, and source scope.
- Prefer accepted evidence packets before drafting grounded claims.
- Group claims by theme, method, limitation, or evidence role.
- Label claim origin as author-reported, guideline requirement, tool capability, or agent inference when useful.
- Preserve uncertainty in prose or outline form.
- End with unsupported claims or the next smallest evidence action when gaps remain.

Common mistakes:

- Writing confident prose before evidence support exists.
- Hiding unsupported synthesis.
- Blending author-reported claims with agent inference.
