## Operational rules

- Route to this source for narrative synthesis within systematic reviews, especially when the user asks for a framework or transparent process.
- Treat the duplicate `extra_1` Markdown as the same captured PDF content, not a separate independent source.
- Use the local capture for the four-element framework and the example comparison only; recapture the full PDF if detailed tool definitions are needed.
- Pair with SWiM or Cochrane Chapter 12 when the task asks for reporting without meta-analysis in intervention reviews.

## Common misuses

- Treating this as a reporting checklist equivalent to PRISMA or SWiM.
- Treating the local one-page capture as the full York guidance document.
- Applying the 2006 framework to all narrative, scoping, state-of-art, realist, or meta-narrative reviews without checking design-specific sources.
- Claiming a fixed mandatory order for tools and techniques when the local capture emphasizes justified choice.
