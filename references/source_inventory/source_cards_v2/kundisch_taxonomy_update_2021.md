## Operational rules

- Route here when the user needs taxonomy-design guidance beyond the original Nickerson 2013 method: evaluation goals, taxonomy operations, reporting transparency, ex post evaluation, or iterative updates.
- Use `nickerson_taxonomy_2013` as the primary source for the original meta-characteristic, ending-condition, and empirical/conceptual iteration method; use this card for the update layer.
- For survey-taxonomy work, explicitly state the target phenomenon, intended purpose, and target users before choosing or revising dimensions.
- Treat search and screening references inside the status-quo study as background to this article's sample construction, not as an SR search-method authority.

## Common misuses

- Using this article as a general systematic review conduct or reporting guideline.
- Treating the 26 TDR as a universal checklist for survey quality outside taxonomy design.
- Ignoring the article's limits on method configuration and naturalistic evaluation.
- Citing the HTML table placeholders when the exact table details require the PDF or supplementary Markdown.
