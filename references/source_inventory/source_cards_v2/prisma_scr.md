## Operational rules

- Use PRISMA-ScR for scoping-review reporting structure and checklist item routing.
- For general literature surveys, use PRISMA-ScR only when the task is explicitly scoping-review-like or when the transfer is labeled as reporting support.
- Keep critical-appraisal claims conditional: PRISMA-ScR tells authors how to report appraisal if done, not which appraisal tool to use.
- Use JBI or another conduct manual when the user asks how to perform the scoping-review process.

## Common misuses

- Treating PRISMA-ScR as a complete scoping-review conduct manual.
- Treating the checklist as a universal narrative or CS/NLP survey-writing method.
- Using PRISMA-ScR critical-appraisal items as a risk-of-bias or certainty framework.
- Citing the source card, manifest, or section index instead of the canonical checklist/page.
