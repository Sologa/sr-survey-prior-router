# API Use Cases

If you have an additional use case, please [contact us](https://developer.ieee.org/contact) to confirm eligibility before moving forward.

## IEEE Content Indexing:

For organizations that desire to extract and index IEEE metadata into a federated or or other search tool to aid discoverability of IEEE content.

## IEEE Open Access:

For organizations looking to review full-text articles designated as Open Access.

## IEEE Full Text Chargeable Access:

For organizations looking to review full-text articles designated as chargeable.

## Text and Data Mining:

For non-commercial research purposes. Researcher must have an eligible IEEE subscription or be associated with an institution / client that has an eligible subscription. Please [contact us](https://developer.ieee.org/contact) for more information.

For API Use Case Examples, please click on [API Use Case Examples](https://developer.ieee.org/docs/read/API_Use_Cases_Examples) for more information.
