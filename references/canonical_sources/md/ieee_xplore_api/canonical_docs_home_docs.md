# Currently Available APIs

Metadata Search API

- Query and retrieve metadata records including abstracts for more than 6 million documents in IEEE Xplore® including Journals, Conference Proceedings, Books, Courses and Standards. The Metadata API supports both simple and Boolean searches .

IEEE Open Access API

- Query and retrieve full-text articles designated as Open Access as well as chargeable Full-Text.

IEEE Full-Text Access API

- Query and retrieve full-text articles designated as chargeable.

Digital Object Identifier (DOI) API

- Query up to 25 DOI (Digital Object Identifier) numbers and retrieve metadata records including abstracts.
