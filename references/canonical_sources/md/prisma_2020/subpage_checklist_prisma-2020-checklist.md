# PRISMA 2020 checklist

The PRISMA 2020 statement comprises a checklist of items and sub-items, and an expanded checklist that details reporting recommendations for each item/sub-item.

-
PRISMA 2020 checklist ( PDF , Word )

-
PRISMA 2020 expanded checklist ( PDF )

The checklist can also be completed using a Shiny App available at [https://prisma.shinyapps.io/checklist/](https://prisma.shinyapps.io/checklist/) or online via the EQUATOR Network’s GoodReports website ( [https://www.goodreports.org/reporting-checklists/prisma/](https://www.goodreports.org/reporting-checklists/prisma/) ).
