# Submission Checklist for Original, First Time Submissions

Original Submission Preparation Checklist

- For resubmissions (revise & resubmits), refer to this [checklist](https://submissions.cljournal.org/index.php/cljournal/ResubmissionsandFinalAccepts) .

- For final version submissions , refer to this [checklist](https://submissions.cljournal.org/index.php/cljournal/ResubmissionsandFinalAccepts) .

Checklist for Original Submission :

- Create a profile if you don't have one; otherwise, login.

- Authors must include their names and affiliations on the first page of the submitted manuscript, as indicated in the style files. Computational Linguistics has a single-blind review process : authorship of submissions is known to the editorial board and the reviewers; authors will not know the identity of the reviewers.

- Formatting : Follow Origina l, Final or Revised Version Instructions and Submission Format (see below).

- Mandated Author Information: Please provide author names (first & last, no initials), affiliations and email address. Provide this in the Contributors section under Publications .

- Please submit the following under “Comments to the Editor”

- Key Words: Please provide 5-10 key words related to your paper; you can enter them in the "Comments for the Editor" section.

- Declarations : Please confirm that :

- the submission has not been published elsewhere : in or submitted for publication to another refereed archival publication.

- the submission has not appeared in any conference or workshop proceedings. (Substantially extended versions of conference papers are acceptable as submissions. Please notify us at the time of submission if this applies.)

- Disclosure Agreement : Note that the submission is not covered by a non-disclosure agreement and is available for peer review without restriction.

Format/Style Files : the paper is in PDF format , in accordance with our guidelines:

- [clv2025.cls](https://submissions.cljournal.org/stylefiles/clv2025.cls) : this is the most recent version of the CL LaTeX macros, provided by the typesetter; by using these macros, you should get your paper looking close to the form in which it would appear in the journal [last updated 2025-01-01].

- [COLI-manual.pdf](https://submissions.cljournal.org/stylefiles/COLI_manual.pdf) : this document, set using clv2025.cls, provides instructions on how to use the style file [last updated 2025-01-01].

- [COLI-template.pdf](https://submissions.cljournal.org/stylefiles/COLI_template.pdf) : this demonstrates the various elements of a CL article. [last updated 2025-01-01].

- [COLI-template.zip](https://submissions.cljournal.org/stylefiles/COLI-template.zip) : this package contains the LaTeX source for producing the above PDF file, as well as other necessary files. [last updated 2025-01-01].

- [compling.zip](https://submissions.cljournal.org/stylefiles/compling.zip) : this contains the style file for setting your citations and references. Please refer to COLI-manual.pdf for instructions to use.

- [alocal.sty](https://submissions.cljournal.org/stylefiles/alocal.sty) : a patch for using clv2025.cls with the ArabTeX package.

Copyright : The authors are able to assign copyright to the Association for Computational Linguistics, should the submission be accepted.
